## Application runtime AI

The optional “Ask about this fundraiser” feature presents a chat-style panel. While it remains open, a request may include up to two completed recent question/answer pairs for the same campaign so the model can interpret follow-ups. This context is transient: closing the panel or changing campaign clears it, and conversation content is not persisted to the database, analytics, or ordinary logs. Every response is grounded in fresh campaign records and the current visitor's authoritative funding snapshot; average contribution is calculated server-side from raised cents and completed contribution count. The model defaults to `gpt-4.1-mini-2025-04-14` and can be changed with `AI_MODEL`; `OPENAI_API_KEY` is required for live runtime answers. Requests set `store: false`. Structured output, citations, and funding placeholders/facts are validated before current values are rendered.

The Campaign Watch feed makes no runtime model requests. Its clips use licensed illustrative stock footage with authored campaign story copy and captions; the demo donation is simulated. Watch browser tests use controlled fixtures, and the swipe-and-donate recording made no AI provider calls. See the [Watch validation record](evidence/watch-20261016/validation.md).

A final eight-case live streaming chat journey is saved at [`chat-live-evaluation.json`](evidence/chat-live-evaluation.json). All eight SSE requests passed; the primary Codex agent reviewed each answer against the selected fictional source material and the current visitor funding snapshot. The run included direct and contextual average questions ($130.36 for $14,600 / 112), then a $112 simulated contribution followed by the updated average ($130.19 for $14,712 / 113). Six supported answers emitted validated partials; two missing-information answers appeared at completion. Three reviewed screenshots are retained in [`docs/evidence/chat/`](evidence/chat/). Across the conversational work, the runtime evaluation process made 31 live model requests: eight initial development cases, eight refined pre-stream adapter cases, seven pre-stream UI cases before a harness assertion stopped the run, and eight final streaming UI cases. The harness stopped on a formatting expectation (`$112` versus `$112.00`), not an application failure. Earlier artifacts remain distinct: [`chat-grounding-evaluation.json`](evidence/chat-grounding-evaluation.json) is the reviewed pre-stream adapter run, [`chat-grounding-development.json`](evidence/chat-grounding-development.json) is its 7/8 development iteration, and [`ai-live-evaluation.json`](evidence/ai-live-evaluation.json) is the reviewed single-turn release evaluation. See [AI evaluation](ai-evaluation.md). Fixture content is fictional; the allowed funding snapshot can reflect the current visitor’s simulated contributions. Raw donation records, private profile notes, and cookie values are not included as conversation memory or analytics data.

No Anthropic API key or API billing was used for the application runtime. Developer subscription access and runtime API credentials/billing are separate.
